# Prakash Bhabad · Portfolio

Product manager who builds. Health AI, AI evaluation and products for India.

Plain HTML, CSS and JavaScript. No build step, no libraries. Hosted free on GitHub Pages.

## Page order

1. About: who I am, key numbers, what I do, what fascinates me
2. Experience: Anjani Innovations (PM intern) and Orange Business (data science intern), each with a diagram
3. Projects: building now, just shipped, the Spotify Wrapped case study, and every other project
4. What I'm looking for: roles, plus a skills matrix that links each skill to the projects that prove it
5. My journey: the metro map of everything so far, and a timeline
6. Contact

## Files

| File | What it holds |
|---|---|
| `index.html` | Page structure and all fixed text |
| `style.css` | Colours, fonts and layout |
| `data.js` | **Every project and job.** The project cards, detail panels, search and metro map all read from it |
| `app.js` | Charts, metro map, story player, skills matrix, panels and search |
| `assets/work/` | Screenshots and figures from my own projects |
| `assets/photos/` | Photos from Unsplash (credited in the footer) |
| `docs/` | Resume and project PDFs |
